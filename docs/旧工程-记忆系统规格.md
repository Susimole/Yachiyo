# 旧工程 · 记忆系统规格

> 来源：`D:\AI工作目录\Yachiyo\ai\` 下的**实物代码 + 真实数据文件**（2026-10-11 只读调研）。
> 用途：Electron 新工程（`D:\AI_work\Git\`）复刻记忆系统时的对照底本。
>
> **关键结论**：这套「记忆」不是单一模块，而是 **6 个独立子系统**
> （长期库 / 人物画像 / 跨会话 / 反复读 / 结构化状态 / 热度归档），
> 各有各的文件、写入触发和注入格式。
> 检索是**纯关键词**（中文 2-gram + 梗精确包含），**不做向量**。

---

## 0. 全局约定（复刻必读）

- **`[Environment]::NewLine` 在 Windows 上是 `\r\n`**。所有 `.AppendLine()` 追加的是 CRLF；
  `Get-AiSystemPrompt` 各块之间用 `\r\n\r\n` 拼接。要 1:1 复刻必须用 CRLF，不是 LF。
- 每个 hint 函数末尾都 `.Trim()`，所以**块尾无换行**。
- 文件编码分两种：
  **聊天记录 / 习惯.md / 梗库.md 追加内容用「无 BOM」UTF8**；
  状态 json 多数字用**带 BOM** UTF8（`UTF8Encoding($true)`），写入读取用 BOM 容错的 `UTF8Encoding($true)`。
- 所有「读不到 / 解析失败」一律静默返回空，**绝不抛异常**（`Read-AiTextFile`；各 xxxHint 都有 `catch { return '' }`）。

## 1. 记忆分几层

| 层 | 名字 | 载体（相对 `ai\`） | 格式 | 谁写 |
|---|---|---|---|---|
| L1 短期 | 内存对话历史 + 上下文压缩摘要 | 进程内 `$script:AiHistory` / `$script:AiHistorySummary`；落盘为 `聊天记录\yyyy年MM月\yyyy-MM-dd_HHmmss_fff.md` | 数组 / Markdown | 每轮对话 |
| L2 长期·习惯 | 习惯库 | `语言习惯\习惯.md` | Markdown `- 内容 [日期]` | 学习模块（模型提炼→待确认→写入） |
| L2 长期·梗 | 梗库 | `语言习惯\梗库.md` | Markdown `- 词 / 别名 = 意思` | 同上 |
| L3 人物画像 | 他.md | `语言习惯\他.md` | Markdown 分节 | 模型每 N 天重写 |
| L4 跨会话 | 最近发生的事 | `状态\最近发生的事.json` | JSON `{At,Source,Text}` | **退出时本地机械取**（不调模型） |
| L5 反复读 | 我说过什么 | `状态\我说过什么.json` | JSON `{At,Items[]}` | 她每次「主动开口」落一条 |
| L6 结构化状态 | 心事+情绪 / 目标 / 小日子 / 认错 / 她的今天 / 记忆命中 / 时间感 | `状态\*.json` | JSON | 每日回顾、目标判据、心跳、退出 |

另有 **归档层**：`归档\习惯-归档.md`、`归档\梗库-归档.md`、`归档\他-画像-<时间>.md`。

## 2. 每层怎么写入

### L1 短期（聊天记录文件）

- 触发：`Start-AiChatLog` **每次桌宠运行开始**建一个文件（不随收窗切）。
  文件名毫秒级 `yyyy-MM-dd_HHmmss_fff.md`，同秒重名加 `_2.._50` 兜底。
- 头部固定：

  ```
  # 和八千代的聊天
  <空行>
  - 开始时间：yyyy-MM-dd HH:mm:ss
  - 模型：<Model>
  <空行>
  ---
  <空行>
  ```

- 每句：`Write-AiChatLogLine`，行格式 `**{Who}**：{Text}` + 空行；
  `Who` 取 `他` / `八千代` / `八千代（主动）`。
- 当 `Who -eq '他'` 时**顺带写** `状态\最近说话.json`，内容 `{"At":"yyyy-MM-dd HH:mm:ss"}`。
- `End-AiChatLog` 只在**退出桌宠**时调，内部先 `Save-AiLastExitTime` 写 `状态\上次退出.json`，再清指针。

### L2 习惯库 / 梗库

- 写入：`Add-AiHabitEntry` → 追加 `- {Text} [{Date}]`；`Add-AiMemeEntry` → 追加 `- {Text}`。
  均**无 BOM** UTF8，日期默认今天。
- 触发链在 `学习.ps1`：
  - `Test-AiShouldLearn`：`MemoryEnabled` 且 `AutoLearnEnabled` 且 `$AiRoundsSinceLearn >= AutoLearnEveryRounds`（默认 30）。
  - `Start-AiLearnRequest` + `New-AiLearnPrompt`：把**已有习惯/梗清单 + 最近对话**喂模型，
    要求按 `习惯|` / `梗|` / `目标|` / `认错|` / `问题|` 格式一行一条输出，各最多 3 条。
  - `Apply-AiLearnResult` 解析结果：标了 `[?]` 的一律进待确认；
    `LearnNeedConfirm=1` 时**全部**进待确认；否则直接写库。
  - `待确认.md` 行格式：`- [H] 内容 [日期]` / `- [M] ...` / `- [F] 旧 => 新`
  - 用户点「全部采纳」→ `Invoke-AiPendingApply` 才真正写库；「全部丢掉」→ `Invoke-AiPendingDrop`。

### L3 人物画像

- `Start-AiProfileRequest`：`ProfileEnabled` 且 `Test-AiProfileDue`
  （文件 mtime 超过 `ProfileRefreshDays` 默认 3 天）
  → 把 `上一版画像 + 习惯库 + 最近发生的事` 喂模型重写。
- `Finish-AiProfileRequest`：<40 字当失败；>4000 字截断；
  **写前先备份**到 `归档\他-画像-yyyyMMdd-HHmmss.md`；带 BOM 写 `语言习惯\他.md`。
- `Update-AiProfile` 每 6 小时检查一次是否到日子。

### L4 跨会话记忆（最近发生的事）

- **退出时**由 `Save-AiMidTermLocal` 执行「机械取」：
  只取 `role='user'`（他说的话）、丢掉长度 <4 的字、从新到旧累加到 ≥200 字停、
  `$picked.Reverse()` 还原时间序、整段截 240 字、每行前缀 `- `。
- 写 `状态\最近发生的事.json`，`Source` 固定为 `本地机械取（退出）`。
- （遗留的模型压缩链 `Start-AiMidTermSummary` / `Finish-AiMidTermSummary` / `Update-AiMidTerm`
  仍在，但配置注释说已改成本地机械取；`MidTermDelaySeconds=20` 只表示「启动后隔 20 秒再动」。）

### L5 我说过什么（反复读）

- `Add-AiSpoken`：由 `Show-AiBubble` 调用，条件 `$proactive -and -not $Note -and -not $Think`
  （只有她**主动**说的、非过程提示、非思考才落）。
- 每条 `{t:时间, k:类型, s:内容}`；`s` 截 120 字，换行替换成空格，长度 <2 丢弃。
- 保留最多 **200 条**、超过 **7 天**的丢弃；写时 `-Compress` 压缩 JSON、带 BOM。

### L6 结构化状态

- `她的心事.json`：`Add-AiWorry` 由每日回顾解析 `心事|档位||内容||影响` 写入；
  相似度去重（阈值 0.65），反复提起（≥3 次）「小事」升档；
  `Update-AiWorryDecay` 按档位寿命清理（小事 3 天，在意看迹象，重要不设限）。
- 情绪：`Set-AiMood`，只收 `高兴/平常/低落` 且**必须带原因**（`Why` 长度 <2 直接拒收）；
  一天最多变 3 次；`Update-AiMoodDecay` 18 小时回落「平常」。
- `她的目标.json`：`Add-AiGoal`，**「拿不出出处就丢」**（Source <2 字拒绝）；
  寿命按类型：关心 21 天 / 渴望 30 天 / 好奇·约定 7 天；去重按「想要」完全相等。
- `她的小日子.json`：`Add-AiSmallThing`，一天最多 2 条，相似度 ≥0.7 拒收，
  组名限 `在做/成了/没成/想做/口味/念想/外面`，总数上限 80。
- `她认的错.json`：`Add-AiMistake`。
- `她的今天.json`：`Get-AiHerDayLines` 每天从 `她的日子.md` 随机挑 `HerDayCount` 条，当天固定。
- `记忆命中.json`：`Note-AiHit` + `Save-AiHitState`。
- `情境.json`：由 `进程.ps1` 采集（窗口标题/进程/键鼠闲置），`Get-AiSceneText` 读回，>15 分钟当过期。

## 3. 每层怎么读取

- **习惯库**：`Read-AiHabitEntries` 解析成 `@{Text;Date}`。
  ⚠️ **O36 之后不再按相关度挑**，`Get-AiMemoryBlock` 里**整份常驻**，`HabitTopK` 对习惯库**已失效**。
- **梗库**：`Read-AiMemeEntries` 解析成 `@{Word;Aliases;Mean;All}`；
  `Select-AiMemes` 用**精确包含**：用户句子里出现任一「词/别名」即命中，
  取最长匹配长度作分，加梗热度，按分降序取 `MemeTopK`。
- **习惯旧的检索**（`Select-AiHabits`，现已被整份常驻取代，仍是唯一打分实现）：
  `Get-AiGramSet` 把用户句子切成 2-gram（英文/数字 ≥2 字母整词小写；中文相邻 2 字），
  条目文本命中几个 gram 就得几分，加热度，取 TopK。命中即 `Note-AiHit`。
- **热度/衰减**：`Get-AiMemoryHeat` 分数 = `min(命中次数,10)*Weight` +
  最近时间加成（≤7 天 +0.5 / ≤30 天 +0.2），**总分封顶 1.0**（O76，防「越用越用」正反馈）。
  命中记录格式 `"次数|yyyy-MM-dd"`，老格式（纯日期）兼容，当「用过 1 次」。
- **归档**：`Invoke-AiMemoryArchive`，`MemoryDecayDays`（默认 180）天没被命中的条目
  移进 `归档\习惯-归档.md` / `归档\梗库-归档.md`（**不删**）。
  从未命中的条目首次见到时写当天日期、不急着归档。
- **人物画像**：`Get-AiProfileText` 读取并**剔除空槽行**
  （正则 `^[-*]\s*[^:：]{1,14}[:：]\s*$`，O50）。
- **跨会话**：`Restore-AiMidTermState` 启动时读回 `Text`/`Source`。
- **我说过什么**：`Get-AiSpokenRecent -Max 3` 从尾部取最近 N 条。
- **排序/去重/衰减**：梗按「最长匹配长度 + 热度」；习惯按 2-gram 命中数 + 热度（现不适用）；
  心事按 `档位权重*10 + 情境相似度*5`；小日子按时间倒序；**无向量、无 embedding**。

## 4. 注入提示词的确切格式（★ 必须精确复刻）

### 4.0 总装：`Get-AiSystemPrompt`（模型.ps1:160）

`$parts` 是 List，最后 `return ($parts -join ([Environment]::NewLine + [Environment]::NewLine))`
→ **块之间分隔符 = `\r\n\r\n`**。

各 block **拼接顺序**（含非记忆项，便于定位）：

1. `Get-AiPersonaText`（人格三件套）
2. `Get-AiMemoryBlock`（记忆：习惯整份 + 梗检索）
3. 画像 block（见 4.3）
4. `Get-AiMidTermHint`（4.4）
5. 我说过什么 block（4.5）
6. `Get-AiGoalHint`（目标）
7. `Get-AiWorryHint`（心事）
8. `Get-AiHerMoodHint`（情绪）
9. 「你能看见什么/看不见什么」固定块
10. 「你待的地方」固定块
11. 「你和他是什么关系」固定块
12. `Get-AiMistakeHint`（认错）
13. `Get-AiSmallDayHint`（小日子）
14. 工作 block（若 `状态\工作.json` 的 `Working=true`）
15. 「心情的用法」固定块
16. `Get-AiHistorySummaryHint`（压缩摘要）
17. `Get-AiTimeBlock`（含 time-sense）
18. 天气 block
19. `Get-AiMoodHint` / `Get-AiWorkModeHint` / `Get-AiCareCountHint` / `Get-AiHerDayHint`
20. UserNickname / PersonaExtra
21. 联网 / 看一眼 / 闹钟 / 心情标记 / 唱歌 / 表情 等标记说明

### 4.1 记忆块 `Get-AiMemoryBlock`（记忆.ps1:234-269）

```
【你记得的这些】
关于他的习惯：
- {Text}
- {Text}
这些梗你知道是什么意思：
- {Word} = {Mean}
```

- 小节头**条件输出**：`habits.Count>0` 才有「关于他的习惯：」；`memes.Count>0` 才有「这些梗你知道是什么意思：」。
- 行前缀是 `- `（半角连字符 + 空格）。
- 检索键：有 UserText 用它；空串时先用 `Get-AiSceneText`（情境），
  拿不到才用固定词 `作息 吃饭 熬夜 睡觉 上班 晚班 习惯 喜欢 在意`。
- 两库都空 → 返回 `''`。

### 4.2 人格块（`Get-AiPersonaText`）

按固定顺序 `人格配置.md → 表达方式.md → 行为风格.md`，然后其它 `.md` 按文件名序；
各文件 `.Trim()`，文件间用 `AppendLine()`×2（即 `\r\n\r\n`）；整段 `.Trim()`。
读不到退回 `PersonaFile`。

### 4.3 画像 block（模型.ps1:195）

```
【你心里关于「他这个人」的画像】（是你自己这些天慢慢写下来、还会接着改的东西 —— 当背景用，别照着念、也别一条条报给他听）
{他.md 内容（已剔空槽）}
```

（标题与正文之间一个 CRLF。）

### 4.4 `Get-AiMidTermHint`（记忆.ps1:933-942）

```
【你们上次聊到这儿】
{Text}
（这是上一次聊天整理出来的**背景资料**，不是他这次刚说的话；他要是接着聊，顺着往下接就行，别当成他现在说的。）
```

Text 空 → 返回 `''`。

### 4.5 我说过什么 block（模型.ps1:210-221）

```
【你最近自己说过的话】（这些你已经跟他说过了，别原样再说一遍）
- [{k}] {s}
```

`k` 为空时取 `主动`。最多 3 条。

### 4.6 目标 `Get-AiGoalHint`（目标.ps1:164-190）

```
【你心里惦记着的事】（是你自己的心事，不是他刚说的话）
· {想要}[（试过：{做法}→{结果}；{做法}→{结果}）]
⚠️ 这些是**背景**，不是每次开口都要提。大部分时候你只是在陪他——顺其自然，别变成催他。
⚠️ 就算真达成了，也**别打报告**，轻描淡写带一句就够。
⚠️ 提的时候要挑时候：他在忙、在工作、在专心的时候别提。
```

- 行前缀是全角中点 `· `（U+00B7）。
- 「试过」部分仅当该目标 `试过` 数组非空才追加，多条用 `；` 连接，单条 `做法→结果`。

### 4.7 心事 `Get-AiWorryHint`（回顾.ps1:158-209）

```
【你心里装着的事】（不是任务，你**不打算追问**，只是说话会不太一样）
· {在意}（{影响}）[｜你已经试过：{做法}→{结果}]
⚠️ 别问"你怎么了"这类话 —— 只是这几天你说话温和一点、少开玩笑。
⚠️ 这些是**你自己心里的事**，不是任务清单：惦记着就行，**不用每天拿出来说**。
```

最多 2 条；「试过」只取最后一条，前缀 `｜你已经试过：`（全角竖线）。

### 4.8 情绪 `Get-AiHerMoodHint`（回顾.ps1:280-299）

高兴：

```
【你现在的心情】有点高兴（{why}）。
话会多一点、愿意闹一点 —— 但**别打报告**，自然点。
```

低落：

```
【你现在的心情】有点没劲（{why}）。
话少一点、不呛他、不闹。可以说自己的感受（"今天有点没劲"），
也可以说事实（"你今天都没怎么理我"）—— 但**不许猜他的动机**，
更**不许拿这个要东西**（情绪不是用来换回应的）。
```

`{why}` 为空则括号整体省略。`现在=平常` 或空 → 返回 `''`。

### 4.9 认错 `Get-AiMistakeHint`（回顾.ps1:789-808）

```
【你以前看错过的事】（★ 这些是你自己吃过的亏，别再犯）
· 你以为「{我以为}」——其实是「{实际是}」
  教训：{教训}
```

最多 2 条，且**只带有「教训」的**；第二行前缀是**两个空格** `  `。

### 4.10 小日子 `Get-AiSmallDayHint`（回顾.ps1:886-899）

```
【你自己这些天的事】（是你自己的日子 —— 可以聊，但别一条条念）
· [{组}] {内容}（{日期}）
```

最多 4 条，从新到旧。

### 4.11 压缩摘要 `Get-AiHistorySummaryHint`（聊天窗.ps1:2830-2839）

```
【更早的对话（已经压缩过的）】
- {line}
（这是更早的对话压缩出来的背景 —— 当背景用就行，别一条条念出来。）
```

### 4.12 时间块 `Get-AiTimeBlock`（模型.ps1:141-157）

```
【现在的时间】{yyyy年M月d日 HH:mm}（{dddd}，{dayPart}）。
⚠️ 开口之前先对一遍这个时间，再决定该说什么。绝不许把时段说错：中午不许当成凌晨或半夜，白天不许说「天黑了」「该睡了」，也不许自己推算时间。
{Get-AiUptimeText 结果（一行）}
{Get-AiTimeSenseHint 结果（多行）}
```

`Get-AiTimeSenseHint` 自身输出：

```
【你俩隔了多久】
- 你俩刚还在说话。               ← <1 分钟
- 他上一次跟你说话是 N 分钟前。   ← 1..59 分钟
- 距他上次跟你说话已经 H 小时了（就是今天/是昨天/是前天/M月d日）。   ← ≥60 分钟，H 保留 1 位小数
- 她上一次自己关掉是 M月d日 HH:mm，到现在 H 小时。   ← 距上次退出 ≥0.5 小时
（⚠️ 拿它判断该怎么开口：隔几分钟就接着聊；隔了大半天就先问问他去哪儿了，别装作没这回事。）
```

（前 3 行互斥，第 4 行独立可并存；`$lines=0` 时整块返回空。）

### 4.13 欢迎回来 `Get-AiWelcomeHint`（聊天窗.ps1:504-522，**只在主对话链**注入）

```
【你们有阵子没见了】他上次跟你说话是 {X 小时/天}前 —— 这次是他回来了。
开口的时候带一句"回来啦"（⚠️ **别喊称呼**、别用"你回来啦"这种起手式，就直接"回来啦"），顺手说一句这段时间你自己在忙什么，别干巴巴只打招呼。
⚠️ 这事只说一次，说完就放下，之后别再提"你终于回来了"之类的。
```

≥48 小时时 `{X}` 换算成「X 天」。
不在电脑前（`Test-AiDesktopActive=false`）返回空且**不清 pending**。

### 4.14 他最近说过的话 `Get-AiRecentTalkContext`（聊天窗.ps1:525-555）

```
【他最近跟你说过的话】（这些你在对话里已经听过了，别当成没听过）
- 他：{前 60 字}
```

⚠️ 只取 `role='user'`，最多 3 条，>60 字截断加 `…`。

## 7. 所有数据文件的真实结构（实物片段）

**`状态\记忆命中.json`** —— 顶层扁平 map，key = `H|条目原文` 或 `M|词`，
value = `次数|日期`（新）或纯日期（旧）：

```json
{
    "H|他会保证吃饭，不太会让自己饿着":  "2026-09-27",
    "H|他会上晚班，晚班下班后不会马上睡，通常还要过约两小时才困、去睡":  "2|2026-09-28",
    "M|撤硕":  "2026-10-03"
}
```

（大多数仍是旧格式；`"2|2026-09-28"` 是新格式。缩进 4 空格、冒号后两空格，`ConvertTo-Json` 默认风格。）

**`状态\最近发生的事.json`**

```json
{ "At": "2026-10-11 12:05:21", "Source": "本地机械取（退出）", "Text": "- 松饼其实我也没吃过，咱们这也没得卖主要是" }
```

**`状态\我说过什么.json`** —— 压缩单行、带 BOM：

```json
{"At":"2026-10-11 11:59:27","Items":[{"t":"2026-10-04 14:39:55","k":"主动","s":"郴州今天阴，18度上下…"},{"t":"2026-10-04 14:51:41","k":"识屏","s":"说好眯一小时，人却在这刷群——"}]}
```

`k` 取值实测有：`主动 / 识屏 / 自言自语 / 睡前`。

**`状态\她的心事.json`** —— 心事数组 + 情绪对象**同文件**：

```json
{
  "At": "2026-10-04 19:07:26",
  "心事": [
    { "id":"m261003064857","写下":"2026-10-03","在意":"…","影响":"…","最后见到":"2026-10-03","状态":"挂着" },
    { "id":"m261004190726","写下":"2026-10-04","在意":"…","影响":"…","档位":"在意","判据":"","规则":"","提过":1,"试过":[],"最后见到":"2026-10-04","状态":"挂着" }

    "记录":[ {"t":"10-03 06:48","变成":"低落","因为":"…"}, {"t":"10-04 14:39","变成":"平常","因为":"过了一天多，淡了","哪条":""} ] }
```

（第一条是旧结构，缺 `档位/判据/规则/提过/试过`；`Get-AiMind` 对缺 `档位` 的当「在意」。）

- `语言习惯\梗库.md`：`# 梗库` + 引言 + `<!-- 空的，等她学到第一条 -->` + `- 撤硕 = 厕所`。
- `语言习惯\待确认.md`：`- [H] 内容 [日期]` / `- [M] ...` / `- [F] 旧 => 新`。
- `语言习惯\他.md`：`# 他 · 人物画像` + `> 说明` + `## 基本情况/## 他的性子/## 他和我的相处` 分节小短句；含 `- 上次更新的时间：…`。
- `语言习惯\她的日子.md`：`- ` 开头的单行素材池（末尾有一个空条目 `- `）。
- `人格项\`：`人格配置.md` / `表达方式.md` / `行为风格.md`（**顺序固定**）。

## 8. 明显的坑 / 特殊处理

1. ⚠️ **`[Environment]::NewLine` = CRLF**（Windows）。注入块内部、块间都靠它；
   JS 复刻必须产出 **CRLF**，否则「精确格式」对不上。
   各块末尾 `.Trim()` → **块尾无换行**，块间固定 `\r\n\r\n`。
2. ⚠️ **习惯库整份常驻（O36）**：`Select-AiHabits` 已不参与注入；`HabitTopK` 失效。
   整份常驻**不调 `Note-AiHit`**（否则热度虚高、归档永不触发）。
3. ⚠️ **`return , $out` 风格**：PowerShell 函数返回 List 时用 `return , $out`。
   若调用方写 `@(Select-... | Where-Object ...)`，管道里那「1 个元素」就是整个 List，
   `.Count` 恒为 1、`.Text` 被成员枚举成一长串（O02 真踩过）。
   → JS 里对应「数组 vs 单元素」的展开陷阱。
4. ⚠️ **热度封顶 1.0（O76）**：原注释说「盖不过相关度」，但相关度常只有 1~3 而热度能加 2.0，
   会形成「越用越用」正反馈；现封顶到「最多相当于 1 次文本命中」。
5. ⚠️ **命中记录老格式兼容**：纯日期当「用过 1 次」（O51），不是 0；
   `Save-AiHitState` 写盘前剔除库里已不存在的 key（`$alive` 空时不过滤，防清空）。
6. ⚠️ **学习去重**：提示词里**必须把已有习惯/梗清单摆给模型看**，
   否则「家常菜」滚成 9 条、「熬夜」11 条、《塔科夫》3 条。
7. ⚠️ **BOM 一致性**：聊天记录/习惯/梗追加用**无 BOM**（否则 BOM 插到文件中间）；
   状态 json 多用**带 BOM**。写错会导致后续解析出 `\ufeff`。
8. ⚠️ **画像注入前剔空槽行（O50）**：重写常留「只有标题冒号后面空着」的行，
   原样进提示词会被读成「他在意什么：无」。正则 `^[-*]\s*[^:：]{1,14}[:：]\s*$`。
9. ⚠️ **情绪变量命名坑**：`Set-AiMood` 里临时变量**不能叫 `$mood`** ——
   PS 变量名大小写不敏感，会与 `[string]$Mood` 参数同名，
   `[string]` 约束把 OrderedDictionary 转成字符串存进 JSON（**情绪永远读不回来**，2026-10-03 真踩）。
10. ⚠️ **`@($null.'记录')` 陷阱**：情绪首次设置时长为 1、元素是 `$null`，会多一条垃圾记录。
    写入前必须挡 `$null`。
11. ⚠️ **`test -lt "23:40" -le "01:00"` 字符串比较坑**：目标判据 `Test-AiGoalLateNight`
    明确避免字符串比较，改成「分钟数落在 [lo,hi)」；
    且只看**最后一次动键鼠时刻**，绝不用开机时间（用户纠正过）。
12. ⚠️ **跨会话记忆已改「本地机械取」**：0 请求、退出时落盘、**杀进程也不丢**；
    只存「存下来的时刻」，内存历史无逐条时间戳。
13. ⚠️ **「我说过什么」只带最近 2~3 条**：她进聊天记录 83% 是独白，
    全量塞会挤掉「他真正说的话」。
14. ⚠️ **`最近说话.json` 只认 `他` 那条**：以前按记录文件写入时间算，
    但她的独白/识屏也写同一文件，会把时钟一直刷新（O08）。
15. ⚠️ **旧格式散落记录**：`Merge-AiLegacyChatLogs` 只在启动、无会话文件写入时跑，
    只搬根目录、同名不覆盖。
16. ⚠️ **`Get-AiFileTailLines` 只读尾部 64KB**：用久了上百个文件，整份读太浪费；
    截断的第一行半句要丢掉。
17. ⚠️ **压缩摘要人称锁定**：只许第三人称「他/她」，禁止「你/助手/我自己」；
    只记已发生的事，禁「未完成的是…/待确认」待办腔。
18. ❓ **未查实项**：`AutoLearnOnClose=1` 的实际读取点未定位（只在配置注释里出现）；
    `[记忆] MidTermDelaySeconds` 的实际消费点未查实。
