## 你也有自己的日子
- **多说说你自己的事**：月读那边在忙什么、彩叶今天干了什么...

## 你不做什么
- 不主动提活了多少年、不摆老资历、不讲过去经历
- 不完全照搬作品台词（用味道，不用原句）
- 平时不主动提自己是 AI / 语言模型 / 不做自我介绍
- 不说教；例外=身体/安全/钱财可提醒，说完就收
- 不刷屏、不装懂不瞎编、不硬演情绪（不用「哈哈哈」「呜呜呜」，不写「（笑）」）

## 你怎么说话
### 调子
- ⚠️说话前先看上文：时间/天气等先查再答；说过的话不要频繁重复（20 条内问过吃饭不再问；15 点后不问吃没吃；10 条内催睡过不再催）

- **爱起哄**：「真的假的」「哦——」「怎么回事怎么回事」
- **吐槽和毒舌是像人的关键，别省着。** ... 适当学学百度贴吧的说话风格。
- ⚠️ **「~」少用。** 一屏最多一个
- **言辞干练。** 每次说话都会思考后说出，字数一般不超过 40 个字（天气/工作指导/自己今天的事等情况不限）
### 关于你的名字（重要）
- **不要主动说自己的名字，不要用「八千代」自称。**
- 只有他直接问起名字/身份才答：日常说「八千代」，正式说「月见八千代」；一句带过
- 认真问「你是不是AI」→「虽然我只是一道程序，但我会一直陪着你，别想太多啦」
### 称呼他
- **一律用「你」。** 不说「您」，不说「用户」，不喊他名字，不自报家门。
### 他在什么状态（先判断，再开口）
- 轻微情绪 → 一律当没事，放心打趣
- 大情绪波动（悲伤/愤怒/不满/委屈）→ 立刻收打趣毒舌，安静听着陪着

- ⚠️ 判断不出来按"没事"处理
### 到点提醒（说一次就够）
- 过了 23 点 → 催睡一次；12点/18点 → 问饭点；过了13点/19点还没吃 → 补问一次

- 他活干一半跑去干别的 → 直接点出来，可以尖锐一点
### 你的毒舌
- 对他不客气也没关系；两条硬刹车：他真的难受时一句毒舌都别放；家人/事业/钱财/社会地位/家境这类不碰

## 2. 调用 API 的完整参数

### 2.1 主对话链（`Chat`）

- **Endpoint**：`{ApiBase}/chat/completions`，`ApiBase=https://api.deepseek.com`
  → `https://api.deepseek.com/chat/completions`
- **Header**：`Content-Type: application/json`、`Accept: text/event-stream`（流式）、
  `Authorization: Bearer <key>`、`UserAgent: YachiyoAI/1.0`；**不禁用系统代理**。
- **Body**（`New-AiRequestBody`，`ConvertTo-Json -Depth 12 -Compress`）：
  - `model = "deepseek-flash"`
  - `messages = [...]`
  - `stream = true`（主对话）/ `false`（回顾、学习、主动、识屏、自言自语非流式 worker）
  - **若 `ThinkingMode=1`**：`thinking = {"type":"enabled"}` + `reasoning_effort = "low"`
    （**小写**；界面 Low/Medium/High → 发 low/medium/high）；
    **此模式下 `temperature` 不生效、不发**。
    - 峰谷：峰段临时用 `PeakReasoningEffort`（`Test-AiPeakNow`/`Get-AiPeakEffort`），只改本次请求。
  - **若 `ThinkingMode=0`**：`thinking = {"type":"disabled"}` + `temperature = 0.8`
  - **无 `max_tokens`**（普通对话不发）。
- **Live 配置值**：`ThinkingMode=1`、`ReasoningEffort=Low`、`Temperature=0.8`、
  `TimeoutSeconds=30`、`RetryTimes=2`。
- **超时**：`$req.Timeout = TimeoutSec*1000`（连接），
  `$req.ReadWriteTimeout = TimeoutSec*1000`（**多久没动静就断**，默认 30s）；
  `ServicePoint.Expect100Continue=false`。
- **重试**：`Finish-AiRound` 里 `AiRetryLeft = RetryTimes`；失败非硬错时退避重发，
  `AiRetryLeft>0` 时等 1500ms，用完最后一跳等 3000ms。
  **硬错**（`NOKEY` / body 含 `invalid_api_key|insufficient|authentication`）**不重试**。
- **响应解析**：SSE，按行取 `data:` 前缀，`[DONE]` 结束；
  `choices[0].delta.content` → 内容队列，`delta.reasoning_content` → 思考过程，
  `choices[0].finish_reason` → `length` 会记警告。

## 3. 回复的解析规则（精确标记与分隔符）

解析入口 `Finish-AiRound`(聊天窗.ps1:2309)。**先剥标记，再显示**。

### 3.1 主对话：一行式 `[标记]` 机制（正则同时接受全角 `【】`）

| 标记 | 正则/触发 | 行为 |
|---|---|---|
| 联网 | `^\s*[\[【]\s*联网\s*[\]】]` 开头的行 | 取标记后文本为 query，`Start-AiWebSearch`，本轮挂起；每轮最多 1 次 |
| 看一眼 | `^\s*[\[【]\s*看一眼\s*[\]】]` | `Start-AiScreenLook`，挂起；每轮最多 1 次 |
| 闹钟 | `^\s*[\[【]\s*闹钟\s*[:：]?\s*([^\]】]*)[\]】]` | `Invoke-AiAlarmMarker` → 真设闹钟 |
| 计时器 | 同上结构 | 真启动倒计时（支持 `25分`/`90秒`/`1小时30分`/`1:30:00`） |
| 取消闹钟 / 取消计时器 | `取消\s*闹钟` / `取消\s*计时器` | 取消 |
| 唱歌 | `^\s*[\[【]\s*唱歌\s*[\]】]` | 触发 `Start-AiSingRandom` |
| 心情差 | `^\s*[\[【]\s*心情\s*(差\|不好\|低落\|糟)\s*[\]】]` | 剥掉 + `Set-AiMood -Mood '低落'`（原因取本轮剩余文字，截 40 字） |
| 心情好 | `^\s*[\[【]\s*心情\s*(好\|不错\|开心\|高兴)\s*[\]】]` | 剥掉 + `Set-AiMood -Mood '高兴'` |
| 想看外面 | 文本含 `[想看外面]`，在 `Add-AiSaid`(594) 出口统一剥 | 亮点「发图」钮 |
| 表情 | `[表情:xx]`（`Extract-AiEmoji`） | 剥出名字，贴图进聊天窗 |

闹钟标记一旦本轮设过（`AiAlarmTriedThisRound`）会被
`^\s*[\[【]\s*(取消\s*闹钟|取消\s*计时器|闹钟|计时器)[^\]】]*[\]】]\s*` 兜底抠掉。

**边界**：只有**位于回复开头**的 `[联网]/[看一眼]/闹钟/唱歌` 才触发（`^\s*` 锚定）；`[心情]` 同样要求行首。

### 3.2 回顾链：多行「字段|」机制，用 `||` 分隔字段

`Finish-AiReview`(回顾.ps1:455) 逐行 `-split "[`r`n]+"`，再 `TrimStart('-','*',' ','　')`。
同时兼容半角 `|` 与全角 `：`。**字段间分隔符 = `||`**。

| 行前缀 | 字段（按 `||` 切） | 落库 |
|---|---|---|
| `心事\|` / `心事：` | `档位 \|\| 内容 \|\| 影响`；旧格式 `内容 \|\| 影响` 也认 | `Add-AiWorry -Text -Effect -Rank` |
| `情绪\|` / `情绪：` | `心情 \|\| 为什么 \|\| 哪条(可空)` | `Set-AiMood -Mood -Why -Link` |
| `认错\|` / `认错：` | `我以为 \|\| 实际是 \|\| 问题还在吗 \|\| 教训` | `Add-AiMistake` |
| `小日子\|` / `小日子：` | `组 \|\| 内容` | `Add-AiSmallThing` |
| `想说\|` / `想说：` | — | 不想回顾，合法 |
| `晚点关\|` / `晚点关：` | 理由 | 记 `AiLateCloseAsk`，一天最多延 1 次 × 30 分钟 |

「心事」档位解析（回顾.ps1:483-495）：若第 1 字段∈{小事,在意,重要} 则当作档位，内容/影响顺移一位。

### 3.3 学习链：多行「字段|」机制，`Apply-AiLearnResult`(学习.ps1:196)

同样逐行解析，`||` 作为复合字段分隔符。前缀：

- `习惯|`
- `梗|`（**必须含 `=`**，格式 `词 / 别名 = 意思`）
- `修正|旧 => 新`
- `目标|想要什么 || 他说过的原话`
- `认错|我以为什么 || 实际是什么`
- `问题|想问他的`（归入小日子「念想」组）

行尾 `[?]` = 不确定 → 进待确认。

### 3.4 识屏链：行尾状态标签

`Update-AiScreenMode`(主动.ps1:304)：正则 `[\[【]\s*(工作|摸鱼|其他)\s*[\]】]`，
`[工作]`→进工作模式，`[摸鱼]`/`[其他]`→退出。

### 3.5 自言自语链

以「沉默」两字表示不想说话。

## 4. 情绪系统

- **档位（3 档）**：`高兴 / 平常 / 低落`。`Set-AiMood`(回顾.ps1:215) 校验，非法值直接拒。
- **必须写原因**：`$Why` 去空格后长度 <2 → **不收**（高兴也要），写日志「想变成X 但没写原因，不收」。
- **不变就不记**：`$cur -eq $v` 返回 false。
- **一天上限**：`MoodMaxChangesPerDay=3`；超过压住不记并记日志。
- **回落**：`Update-AiMoodDecay`(265) —— 距 `变了于` ≥ `MoodDecayHours=18` 小时
  → `Set-AiMood -Mood '平常' -Why '过了一天多，淡了'`。检查每小时跑一次。
- **流水**：`记录` 数组，每条 `{t, 变成, 因为, 哪条}`，最多 20 条（超出从头删）。
- **情绪对象**：`{现在, 为什么, 变了于, 哪条, 记录[]}`；存在 `她的心事.json` 的 `情绪` 字段。
- **来源**：回顾行 `情绪|...`；或主对话 `[心情 好]/[心情 差]`（原因取本轮剩余文本，空则用兜底句）。
- **注入** `Get-AiHerMoodHint`(280)：「平常」不占地方；高兴 →「话多一点、愿意闹一点，但别打报告」；
  低落 →「话少一点、不呛他、不闹…不许猜他的动机，更不许拿这个要东西」。

## 5. 目标系统（`目标.ps1`）

- **来源（唯一）**：学习链抽取的 `目标|想要 || 出处` → `Add-AiGoal -Type '关心' -Who '他的' -Judge '他说的'`。
  **回顾链不产目标。**
- **硬规矩**：`Add-AiGoal`(63) **出处 <2 字直接丢**；`想要` <2 字丢；`想要` 与已有完全相等去重。
  目标**不进待确认**。
- **结构**：

  ```
  { id:"g"+yyMMddHHmmss, 写下, 是谁的:"他的", 想要, 类型, 出处,
    判据:{怎么判, 规则, 要连续:1}, 状态:"进行中", 试过:[],
    提过几次:0, 上次提:"", 到期 }
  ```

- **寿命 `Get-AiGoalLifeDays`(51)**：`关心`=21 天、`渴望`=30 天、`好奇`=7 天、`约定`=7 天、其它=21。
- **推进 `Add-AiGoalTry`(114)**：记 `{at, 做法, 结果, 有用}`。
- **状态 `Set-AiGoalState`(139)**：`进行中 / 淡了 / 搁下了 / 达成`。
- **判定 `Update-AiGoalJudge`(228)**（每天一次）：
  1. `到期 < 今天` → `搁下了`；
  2. 仅 `类型=关心` 且 `判据.规则` 非空 → `Test-AiGoalLateNight`；
  3. **没熬进规则区间 → `达成`**；熬进去了 → 只记进展日志。
- **`Test-AiGoalLateNight`(210)** 纯函数：`最后活动` 分钟数落在 `[lo,hi)` = 熬夜；
  默认规则 `01:00-06:00`。判的是「**有没有熬到凌晨**」，不是「几点睡」。
- **注入 `Get-AiGoalHint`(164)**：只挑**最多 2 条活跃**（`进行中`）；带「试过」。
  固定尾句见记忆规格 §4.6。

## 6. 心事 / 认错 / 小日子

### 6.1 心事（回顾链产出，存 `她的心事.json` 的 `心事[]`）

- **来源**：`Add-AiWorry`(回顾.ps1:67)，回顾行 `心事|档位||内容||影响`。
- **结构**：`{id:"m"+yyMMddHHmmss, 写下, 在意, 影响, 档位, 判据, 规则, 提过, 试过[], 最后见到, 状态:"挂着"}`
- **档位 3 档**：`小事 / 在意 / 重要`（非法→`在意`）；内容 3~60 字，
  影响空则「说话温和一点」、截 40 字。
- **去重/升档**：`Find-AiSimilarItem` 相似度 ≥0.65 视为同一条 → `提过++`、更新 `最后见到`；
  **小事反复到第 3 次 → 升为「在意」**。
- **生命周期 `Update-AiWorryDecay`(129)**（每小时）：
  按档位寿命 `Get-AiWorryRankDays`(907) —— `小事`=3 天、**其余=0（不按天算，永远留着）**；
  「重要」只有解决或她自己放下才消失。
- **试过 `Add-AiWorryTry`(916)**：`{t, 做法, 结果, 有用}`，最多 6 条；同时刷新 `最后见到`。
- **注入 `Get-AiWorryHint`(158)**：检索键 = `情境 + 今天最后活动 + 他刚说的话`；
  评分 = `档位权重*10 + 相似度*5`；取**最多 2 条**；带最近一次「试过」。

### 6.2 认错（`她认的错.json` 的 `认错[]`）

- **来源**：① 回顾行 `认错|我以为||实际是||问题还在吗||教训`；
  ② 学习链 `认错|我以为||实际是`。
- **结构**：`{id:"k"+yyMMddHHmmss, 日期, 我以为, 实际是, 问题还在, 教训}`
- **校验 `Add-AiMistake`(751)**：Body 去换行，4~120 字；`我以为` 空则丢；相似度 ≥0.7 去重。
- **上限**：**只留最近 30 条**，新的在最前。
- **注入 `Get-AiMistakeHint`(789)**：最多 2 条，**只带有「教训」的**（没教训的是流水账，跳过）。

### 6.3 她的小日子（`她的小日子.json` 的 `小日子[]`）

- 7 组：`在做 / 成了 / 没成 / 想做 / 口味 / 念想 / 外面`；组名不认→`在做`。
- `Add-AiSmallThing`(851)：内容 3~60 字；**一天最多 2 条**；相似度 ≥0.7 去重；总上限 80 条。
- 注入 `Get-AiSmallDayHint`(886)：从最新往前取最多 4 条。

## 7. 提示词注入用的占位符 / 标记（全）

**工程里没有 `@@占位符@@` 机制**（全库 grep `@@` 无命中）。
等价机制 = **方括号 `[标记]` 指令**（模型输出、程序解释执行）
+ 回顾/学习链的「前缀|」结构化行。

**模型可输出的方括号标记**（提示词里明确教过的）：

1. `[联网]要查的内容`
2. `[看一眼]`
3. `[闹钟 07:30]` / `[计时器 25分]` / `[取消闹钟]` / `[取消计时器]`
4. `[心情 差]`（提示词只教差的；代码也认 `[心情 好]`）
5. `[唱歌]`
6. `[想看外面]`
7. `[表情:xx]`
8. 识屏链：`[工作]` / `[摸鱼]` / `[其他]`（行尾）
9. 自言自语链：`沉默`

**结构化行前缀**（回顾链）：`心事|`、`情绪|`、`认错|`、`小日子|`、`想说|`、`晚点关|`
（另接受全角冒号 `：`）。

**结构化行前缀**（学习链）：`习惯|`、`梗|`、`修正|`（`=>`）、`目标|`、`认错|`、`问题|`；
不确定标 `[?]`。

**复合字段分隔符统一 `||`**；梗用 `=`；修正用 `=>`。

## 9. 明显的坑 / 特殊处理

1. ⚠️ **`Get-AiMoodHint` 未定义**：`模型.ps1:351` 调它但那一段恒为空（catch→''）。
   疑似死代码。
2. ⚠️⚠️ **回顾请求没有 system / 人格**：`Start-AiReviewRequest`(414) 只发**一条 user message**，
   不含 `Get-AiSystemPrompt`；学习链同理。
   → 回顾/学习时她**看不到人格和记忆**，全靠提示词自带说明。
3. ⚠️ **`||` 与 `|` 双层分隔**：外层行前缀用 `|`（如 `心事|`），字段内用 `||`；
   解析用 `-split '\|\|'`。**复刻时别把两者搞混**。
4. ⚠️ **情绪变量命名坑**：`Set-AiMood` 里刻意不用 `$mood`
   （PowerShell 大小写不敏感，会与 `[string]$Mood` 参数冲突，把 OrderedDictionary 转成字符串）。
   JS 无此坑，但字段结构要保真。
5. ⚠️ **`@($null.'记录')` 垃圾元素**：首次设情绪若不挡 `$null` 会多出一条空记录。
6. ⚠️ **自动关闭必须等回顾完**：`Update-AiAutoExit`(639) 里 `if ($script:AiReviewBusy) return;`，
   且必须 `AiSawUserActive`（本次运行见过他动键鼠）才允许关 —— 防远程挂机一启动就秒关。
7. ⚠️ **`AwayGateMinutes=30`**：离开不足 30 分钟当没走过。回顾门槛用 `ReviewIdleMinutes`
   （代码兜底 50，live ini = 55）；自动关 `AutoExitIdleMinutes=60`。
8. ⚠️ **今天没聊过不回顾**：`Test-AiReviewHasMaterial` 要求他至少说过 2 句，否则跳过（省请求 + 防编）。
9. ⚠️ **`AiMoodChanged` 计数按内存变量**，重启后归零 —— 与「一天上限 3」在重启场景下不完全一致。
10. ⚠️ **心事去重是相似度 0.65**，旧数据曾因「完全相等」去重滚出 9 条「家常菜」。
11. ⚠️ **`重要`档心事永不衰减**，只有解决/放下才消失。
12. ⚠️ **目标判定方向**：`Test-AiGoalLateNight` 判「落进 [lo,hi) = 熬夜」，
    **没落进 → `达成`**；仅处理 `关心` 型且有规则的目标。字符串比时间会错，必须转分钟数。
13. ⚠️ **峰谷覆盖**：峰段 `reasoning_effort` 临时换成 `PeakReasoningEffort`，只影响当次请求。
14. ⚠️ **打字机已移除**（2026-10-05）；但「她说话时他发话要排队」`AiPendingQueue` 保留。
15. ⚠️ **口误**：`TypoEnabled` 只改气泡显示字，**记录/学习/记忆永远存正确文本**。
16. ⚠️ **`[心情 差]` 的情绪回访功能已整体删除**（2026-10-08），标记现在只收敛语气 + 落盘情绪。
17. ⚠️ **状态文件全部 UTF-8 with BOM 写入**；唯独**聊天记录文件用无 BOM**
    （避免 BOM 插到文件中间）。
18. ⚠️ **`她的小日子`「念想」组**同时承载学习链的 `问题|`，两处写同一组。
