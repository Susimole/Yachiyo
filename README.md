# Yachiyo · 八千代

**一个住在你桌面上的 AI 伙伴。**

不是"助手"，也不是"工具"—— 她会聊天、会记事、有自己的心情和惦记的事，你不在的时候会自己过日子，你回来的时候会跟你说话。

用 **Electron** 写的，没有构建步骤，clone 下来就能跑。

> ⚠️ 这是**个人作品 / 同人项目**，跟《超かぐや姫！》官方没有任何关系。
> 立绘素材是大语言模型辅助生成、再自己抠的，**不是官方资源**。
> 详见底下的[许可](#许可)。

---

## 它是什么样的

- **会动的立绘** —— 分层拆件 + 网格形变骨架。走路、跑、跳、坐着翘脚、睡觉翻身，都是同一个骨架在动。
- **会记事** —— 短期对话、跨会话、从聊天里自动提炼的「习惯」和「梗」、以及她隔几天自己重写的**关于你的画像**。
- **有情绪** —— 高兴 / 平常 / 低落三档，**必须写原因**，18 小时自己淡回去，一天最多变三次（不然那不叫有情绪，叫抽搐）。
- **有自己的东西** —— 心事、认错、以及她自己的小日子（"想做茶碗蒸，蛋液没调对，蒸出来全是蜂窝"）。
- **会回顾** —— 你离开够久，她坐下来把今天想一遍，写进上面那些地方。
- **会自己开口** —— 隔二三十分钟冒一句，带着现在几点、外面天气、以及"你最近已经说过什么，别重复"。
- **会查资料** —— 你问新鲜事的时候，她真去网上搜一次再答。
- **会看一眼** —— （可选，默认关）隔一阵截屏看看你在干嘛，然后说一句。
- **会自己睡** —— 你走了够久，她留一句晚安然后退出；下次开机接着上次。

## 快速开始

### 装现成的

下载 `Yachiyo-x.y.z-安装包.exe` 双击，一路下一步。

装完第一次启动要**填一个 API Key**：右键桌宠 → `API 接入` → 填地址和 Key。

> 默认接口是 **DeepSeek**（`https://api.deepseek.com`，模型 `deepseek-flash`）。
> 任何 **OpenAI 兼容**的接口都能用，把地址和模型名改掉就行。
> ⚠️ 但**联网查资料**那一条走的是 Anthropic 兼容端点（见下面「已知的坑」）。

### 从源码跑

```bash
git clone <这个仓库>
cd yachiyo
npm install
npm start
```

要求：**Node 18+**。`npm install` 会下 Electron 运行时（100 多 MB）。

## 第一次要设置的

| 在哪 | 干什么 |
|---|---|
| 右键桌宠 → **API 接入** | 填接口地址 / 模型名 / API Key。有「模型调试」按钮可以先探测地址通不通、有哪些模型 |
| 设置面板 → **AI 接入 → 识屏** | 想让她看屏幕的话。**默认关** —— 那会把你的屏幕截图发出去，该由你自己开 |
| 设置面板 → **AI 接入 → 联网** | 联网默认开着；想关掉或改每天上限在这 |
| 设置面板 → **高级** | 备份位置、开机自启、偶尔打错字 |

**右键菜单**能就地开关：音效 / 夜间模式 / 桌宠移动。
**设置面板**是完整的那一套（习惯 · 对话框 · 天气 · AI 接入 · 高级 五页）。

## 你的东西存在哪

**`%APPDATA%\Yachiyo\`** —— 不在安装目录里，所以**升级 / 重装都不会丢**。

```
Yachiyo\
├─ config.json          ← 所有设置（他本来就能手改）
├─ persona\             ← 人格（3 个 md，你自己写）
├─ fonts\               ← 界面字体（丢 ttf 进去就能在设置里选）
├─ logs\                ← 她自己那条条链的日志，YYYY-MM.log
├─ 备份\                ← 见下
└─ data\
   ├─ chat.jsonl            对话历史
   ├─ habits.md / memes.md  习惯库 / 梗库（自动提炼出来的）
   ├─ profile.md            关于你的那张纸
   ├─ pending.md            她学到但还没被你点头的东西
   ├─ 她的心事.json         心事 + 情绪
   ├─ 她认的错.json
   ├─ 她的小日子.json
   ├─ 她的目标.json
   └─ state\                各种"上次到哪儿了"
```

**备份**（自动，不用管）：

```
备份\
├─ 聊天记录\26-10\     ← 每天，按年月分文件夹
├─ 日志\26-10\         ← 每天，按天拆开
└─ 记忆\2026-10-19\    ← 每周一个 zip（人格+习惯+心事+状态）
```

> 卸载**不会删** `%APPDATA%\Yachiyo\` —— 你的记忆还在。想彻底清干净得自己删。

## 它内部长什么样

```
src/
├─ main/                主进程（窗口 / 托盘 / 浮层 / IPC）
│  ├─ index.cjs         入口：建窗口、接心跳、装配所有链
│  ├─ overlay.cjs       菜单 / 设置面板 / 聊天窗（各自独立窗口）
│  ├─ preload.cjs       contextBridge 那层（白名单）
│  └─ tray.cjs          托盘
├─ core/                **所有逻辑**（28 个模块，不碰 Electron）
│  ├─ prompt.cjs        提示词总装 —— 她说的话只从这一个地方出
│  ├─ brain.cjs         一次对话的完整流程
│  ├─ memory.cjs        短期 / 跨会话 / 我说过什么
│  ├─ habits.cjs        习惯库 + 梗库 + 热度
│  ├─ learn.cjs         从聊天里提炼习惯和梗
│  ├─ mood.cjs          情绪
│  ├─ heritems.cjs      心事 / 认错 / 小日子
│  ├─ goals.cjs         她惦记着要为你做的事
│  ├─ review.cjs        回顾链（每天一次）
│  ├─ heartbeat.cjs     心跳 —— 只负责"什么时候该跑"，不负责"跑什么"
│  ├─ selftalk.cjs      自言语
│  ├─ autoexit.cjs      准备睡 → 自动关闭
│  ├─ peeker.cjs        识屏调度
│  ├─ capture.cjs       抓屏（desktopCapturer / GDI 两条路）
│  ├─ websearch.cjs     联网查资料
│  ├─ weather.cjs       天气
│  ├─ backup.cjs        备份
│  ├─ log.cjs           落盘日志
│  └─ …（还有 config / store / text / usage / profile / autostart 等）
└─ renderer/            渲染层（纯前端，无构建）
   ├─ app.js            主窗口（她 + 气泡）
   ├─ rig/              骨架引擎（Canvas 2D + 逐切片 setTransform）
   └─ ui/               气泡 / 菜单 / 设置面板 / 聊天窗 / 自绘下拉 / 口误
```

**几条设计上的规矩**（都写在对应文件的注释里）：

- **`core/` 不 require electron** —— 那玩意儿在 node 里跑不起来，自检就没法跑了。
  需要 Electron 能力的地方（心跳的空闲时间、抓屏）由主进程 `attach()` 塞进去。
- **心跳只管"什么时候"** —— 每样活的实现都在各自的模块里。旧版把定时判断和具体活儿
  混在一起，结果"一小时跑一次"这段逻辑被抄了四遍。
- **提示词只从 `prompt.cjs` 出** —— 加一句话只改一个地方。
- **凡是可能"假成功"的链，必须留一个可验收指标写进日志** ——
  比如联网那次"服务端到底搜了几次"。返回 200 不等于真搜了。

## 自己验证

工程里带着**自检**和**探针**，都在 `scripts/`：

```bash
node scripts/selfcheck.cjs        # 外壳（窗口 / 穿透 / 对话链）
node scripts/selfcheck-3c.cjs     # 情绪 / 目标 / 心事 / 认错 / 小日子
node scripts/selfcheck-memory.cjs # 记忆
node scripts/selfcheck-4a.cjs     # 心跳 + 回顾链
node scripts/selfcheck-4b.cjs     # 自言语 + 自动关闭
node scripts/selfcheck-4c.cjs     # 备份
node scripts/selfcheck-4d.cjs     # 「我说过什么」+ 画像重写
node scripts/selfcheck-4e.cjs     # 联网
node scripts/selfcheck-4f.cjs     # 识屏
```

自检**不起窗口、不发真请求**，跑在隔离目录里（`YACHIYO_HOME`），不会碰你自己的数据。

`scripts/probe-*.cjs` 是**真机端到端**探针（起真 Electron、真截屏、真发请求），
验的是"接线通不通"—— 那一段自检够不着。

## 已知的坑

- **联网那条链走 Anthropic 兼容端点**（`<接口地址>/anthropic/v1/messages`）。
  OpenAI 那套的 `tools=[{type:'web_search'}]` **会被服务端静默忽略** ——
  返回 200、一次都没搜、模型拿旧知识编答案。**我在这上面被骗过一整天。**
  所以那条链的日志里会写"服务端搜了几次"：**那个数是 0 就说明它又在骗你**。
- **看图要支持视觉的模型**。识屏那张图发出去，模型看不见的话**不会有任何报错**，
  她只是"看不见"。设置里可以单独指一个 `看图用模型`。
- **独占全屏的游戏**有可能抓出来全黑 —— 那会被判成全黑、跳过这一轮（不花钱）。
  实测大部分全屏游戏（无边框全屏）能抓到。
- **`asar` 关着** —— 装完之后代码是散着的，你能直接改。稳定之后可以打开。
- **安装包没签名** —— Windows 可能弹「未知发布者」，点"仍要运行"。
