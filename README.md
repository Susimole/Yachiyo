# Yachiyo · 八千代

一个住在桌面上的 AI 伙伴。

## 她会什么

- **会动的立绘** —— 分层拆件 + 骨架，走路、跑、跳、坐下翘脚、睡觉翻身
- **会聊天、会记事** —— 记得聊过什么，还能从里面提炼出你的习惯
- **有情绪** —— 高兴 / 平常 / 低落，会自己淡回去
- **有自己的日子** —— 心事、认错、惦记着要做的事
- **会自己开口** —— 隔一阵冒一句，带着现在几点、外面什么天气
- **会查资料** —— 你问新鲜事，她真去网上搜一次再答
- **会看你干啥** —— （可选，默认关）偶尔截屏看看你在干嘛
- **会自己睡觉** —— 你走了够久，留句晚安然后退出

## 第一次要填个 API Key：右键桌宠 → `API 接入`。默认接 DeepSeek。

## 配置文件在哪？

`%APPDATA%\Yachiyo\` —— 不在安装目录，重装不丢。卸载也不删，要清得自己删。
