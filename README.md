# Yachiyo · 八千代

一个住在你桌面上的 AI 伙伴。会聊天、会记事、有自己的心情和惦记的事。
Electron 写的，**没有构建步骤**，clone 下来就能跑。

> 个人作品，跟《超かぐや姫！》官方无关。立绘是 AI 辅助生成 + 自己抠的。

## 怎么用

**装现成的**：下载 `Yachiyo-x.y.z-安装包.exe`，双击，一路下一步。

**从源码跑**：

```bash
npm install
npm start
```

要求 Node 18+。

**第一次要填个 API Key**：右键桌宠 → `API 接入`。
默认接 DeepSeek，任何 OpenAI 兼容的接口改个地址就行。

> ⚠️ 只有**联网查资料**那条链走 Anthropic 兼容端点，见下面。

## 你的东西在哪

**`%APPDATA%\Yachiyo\`** —— 不在安装目录，重装不丢。

```
config.json    所有设置（可以直接手改）
persona\       人格
logs\          日志
备份\          自动备份（聊天记录每天 / 记忆每周）
data\          聊天记录、习惯、心事、画像……
```

卸载**不删**这个目录。想清干净得自己删。

## 已知的坑

- **联网那条链走 Anthropic 兼容端点**。OpenAI 那套的 `tools` 会被服务端
  **静默忽略** —— 返回 200、一次都没搜、模型拿旧知识编。日志里写着
  「服务端搜了几次」，**那个数是 0 就说明它又在骗你**。
- **识屏要看图，得用支持视觉的模型**。不支持的话**不报错**，她只是看不见。
- **独占全屏的游戏**有可能抓出来全黑，那会被判全黑跳过这一轮（不花钱）。
- 安装包**没签名**，Windows 会弹「未知发布者」。
